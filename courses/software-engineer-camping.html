  2. 02

    第一週：HTML 與 CSS 基礎 — AI 帶你寫第一個網頁

    2026/05/08(五) 20:00~22:00

    網頁的一切從 HTML 和 CSS 開始。這堂課帶你認識網頁的骨架與外觀是怎麼組成的，從標籤結構、文字樣式到區塊模型，一步步建立觀念基礎。同時你會學到如何用 AI 工具快速產出 HTML 結構，理解 AI 生成的程式碼在寫什麼，開始培養「看懂 → 修改 → 應用」的能力。

    關鍵字AI 輔助生成網頁、HTML 標籤、CSS 選擇器、文字樣式、區塊模型

  3. 03

    第二週：Flexbox 排版實戰 — 用 AI 搞定版面配置

    2026/05/15(五) 20:00~22:00

    學會基礎後，最常卡關的就是「排版」——怎麼讓元素並排、置中、均勻分布？這堂課教你用 Flexbox 解決九成的排版需求，從容器概念、主軸與交叉軸到對齊技巧。你也會練習用 AI 描述想要的版面配置，產出 Flexbox 程式碼後自己微調，體驗基礎知識如何讓你更有效地駕馭 AI。

    關鍵字Flex 容器、軸線概念、對齊方式、常見排版模式、AI 排版生成

  4. 04

    第三週：RWD 響應式設計 — AI 輔助跨裝置設計

    2026/05/22(五) 20:00~22:00

    手機瀏覽佔了一半以上的流量，網站不能只在電腦上好看。這堂課你會先手寫 media query 理解 RWD 核心觀念，再用 AI 產出完整的響應式佈局，學會判斷 AI 生成的斷點設計是否合理。同時穿插 CSS transition 效果，讓按鈕和區塊開始有互動感，為最後一堂的動畫設計打底。

    關鍵字media query、斷點設計、手機優先、AI 輔助開發、CSS transition

  5. 05

    第四週：AI 動畫設計 — 用提詞庫完成個人網站

    2026/05/29(五) 20:00~22:00

    前三堂你已經有一個具備完整排版、RWD 的個人網站，但它還缺少「讓人想多看兩眼」的動態效果。這堂課你不用背 animation 語法，而是從講師精心設計的「動畫提詞庫」中挑選喜歡的效果名稱，用 AI 生成完整的 CSS 動畫程式碼，再自己調參數放進網站。最後一堂課的重點是「用 AI 創作」——你負責設計感，AI 負責寫 code。

    關鍵字動畫提詞庫、AI 生成動畫、CSS animation、keyframes、Vibe Coding、個人網站完成
