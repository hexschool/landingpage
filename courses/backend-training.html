Q
這個系列課程建議要有 JavaScript 基礎，如何確定我的程度是否適合？

Ａ

本系列課程聚焦在「後端系統建構」，不會著墨於 JavaScript 基礎說明，為了在課程中有較好的吸收與學習體驗，我們預期您已具備以下 JavaScript 基礎：

  • 基礎語法：熟悉變數宣告 (const/let)、解構賦值、陣列操作。
  • 流程控制：理解 if/else、for 迴圈。
  • 物件導向：了解物件（Object）與函式（Function）的基本用法。
  • 非同步初步概念：聽過或曾使用過 AJAX、Promise。
